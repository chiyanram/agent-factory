## Where ours is behind the best source

1. **Agent CLIs (8.2–8.3).** Ours has one live agent CLI, Claude Code; Copilot is off (`src/core/agent/switch.ts:8`). AO
   drives ~40, Optio 8 plus any model through LiteLLM, Sandcastle 6, Factory.ai any OpenAI-compatible endpoint.
2. **Trackers (8.5).** Ours reads only the git host's issues. Symphony ships 5 trackers behind a 6-call behaviour and
   Optio 5 behind `TicketProvider`; Devin and Factory.ai take Linear and Jira. Our `tracker.*` points have no connector.
3. **MCP and outside context (7.1, 8.9).** Ours runs load no MCP server and `context.read` is unused. Every other
   source except AO gives runs MCP tools or connectors (Optio's REST bridge, Factory.ai's ~70 catalog apps).
4. **Plugin governance at scale (7.3, 7.7).** No network install or marketplace for connectors, and no
   allow/forbid manifest like Devin's or `strictKnownMarketplaces` like Factory.ai's. Lower priority for a personal
   deployment (#833).
5. **Where ours leads.** Hash-pinned connectors, an env allowlist, a contract test kit with write fidelity, and
   exact commit + sha256 pins for Claude plugins. No other source has all of them. Optio re-syncs a floating ref,
   Devin and Factory.ai allow unpinned branches, and Symphony trusts hooks fully.
