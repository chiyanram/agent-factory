### Threats

| threat | which sources defend it | ours |
|---|---|---|
| injected run pushes, merges or posts with a git token | Devin (profile can drop `gh` token, git read-only); Optio (repo-scoped helper, narrows only) | **yes**: no git token in any run; host pushes |
| injected run reads host secrets (`~/.ssh`, logins) | Devin, Devin SF (VM); Pocock (private home); Factory.ai (deny lists, if sandbox on); Optio (pod) | **yes**: private HOME, home hidden in srt, container on vm |
| exfiltration over the network | Devin (host/CIDR allowlist); Factory.ai (domain proxy, opt-in) | **partly**: host-name allowlist; an allowed host (model API) can still take data (accepted) |
| repo plants config, hooks or rules that steer the run | Pocock (host git config); Factory.ai (settings protected); Symphony and Optio let the repo set the prompt | **yes**: `--setting-sources user`, `hostGit`, protected files refused at push |
| agent changes CI to steal CI secrets | none found in others | **yes**: host push refuses CI files |
| agent text pings, links or closes tickets | Optio (no outside images) | **yes**: one posting template + PR body cleaner |
| model approves and merges its own PR | AO (human merges); Symphony (human moves ticket) | **yes**: AI never approves; human merges |
| injected text in a ticket or PR comment | Devin (guardrails on messages and PR comments); AO (trust line, prompt only) | **partly**: data fence on outside text, no classifier |
| secrets leak into logs or commits | Factory.ai (Droid Shield on commits); AO, Symphony (log redaction) | **partly**: scrub on records/traces/posts; no secret scan on commits |
| forged human approval | Devin SF (grant never exceeds the giver) | **partly**: hash-bound approval; laptop deny list is no wall (#674) |

## Where ours is behind the best source

1. **Isolation strength.** Devin runs each session in a microVM with its own kernel (`cog:cloud`); ours is a shared-kernel
   container or `srt`, and `srt` is tested only on a fake (#674). Review, design review and onboarder still run on the host (#674).
2. **Egress content.** Ours sees host names only, so the model API can receive data (`safety.md:60`). No source closes
   this; Devin adds CIDR rules, Factory.ai warns the same. A read-only registry mirror is decided, not built.
3. **Caps off by default, no turn cap.** Unset caps are no caps (`caps.ts:41-42`) and the writer has no turn limit;
   Optio and Devin enforce org budgets out of the box and Optio caps turns (250/10).
4. **Injection screening and commit secret scan.** Devin screens messages and PR comments with a classifier
   (`dvn:guard`); Factory.ai scans commits for secrets (Droid Shield). Ours has a data fence and log scrub only.
5. **Audit off the machine.** Ours keeps records local until the PR (#498); Optio, Devin and Factory.ai keep a
   server-side audit log.
