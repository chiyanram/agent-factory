## 2. Reasons shared by ≥2 independent sources

| reason | sources |
|---|---|
| **Protect the coordinator's context**: bulk work goes to workers, and only summaries come back | Anthropic research · Claude Code docs · HumanLayer ("context control") · Pocock chief-of-staff · poteto-mode ("Guard the Context Window") |
| **A fresh worker avoids drift and context rot.** Never resume a worker; respawn it with a consolidated brief | pstack (resumes "silently drop directives") · Factory (fresh worker per feature) · Cognition 2026 (context rot, "focus degrades") · HumanLayer 12-factor (bigger task, longer context, lost focus) · Anthropic ("reduces path dependency") |
| **One point of contact for the human**, so the human does not juggle sessions | firstmate (VISION "One captain, one interface") · openclaw ("single point of contact") · Pocock ("stay in active dialogue with the user") · Factory (Droid does the scoping) |
| **Workers cannot ask questions**, so all human contact (questions included) goes through the coordinator, and the brief must be complete | pstack ("a worker cannot ask you a question") · Claude Code (no `AskUserQuestion` in subagents) · firstmate (crewmates never address the captain) · Cognition 2026 (child-to-manager messaging is not trained) |
| **Intake and planning sit with the agent that talks to the human**, not with a separate planner | Factory (Droid clarifies, then orchestrates) · firstmate (intake plus "one concise question") · openclaw ("ask only for missing facts that block work") · HumanLayer wsff (front-loading alignment) |
| **The coordinator never writes code.** Writes stay single-threaded: one writer per branch | pstack · firstmate hard rule 1 · Cognition 2026 · openclaw ("one owner" per artifact) |
| **Truth lives outside chat memory** (files, forge, wiki), so the coordinator survives compaction and restart | Pocock (wiki) · firstmate ("never in chat memory") · pstack (store and ledger) · Anthropic (plan saved to memory) · Pocock factory (tracker and git host) |
| **Keep it shallow.** Extra layers cost fidelity and tokens | firstmate VISION:38 · pstack (swarm trees "parked as too rigid") · Addy Osmani anti-pattern D |
| **A fresh, independent reviewer** | Cognition 2026 · pstack (verifier on another model family) · agent-factory #4 Q2 |

## 3. Sources that argue the other way

| source | position | why |
|---|---|---|
| Cognition 2025 "Don't Build Multi-Agents" | One single-threaded agent, no split | Workers lose context, and their implicit decisions conflict. The 2026 follow-up keeps this for parallel writers only. |
| Cursor `orchestrate` plugin (Sokolin) | A **script** runs the loop, and the LLM is only the planner | "Long-running agent loops drift; a script with a JSON state file keeps its footing." This argues for a dumb loop with a smart planner. |
| HumanLayer 12-factor (factor 8, factor 10) | Deterministic code owns the control flow. Agents are small steps inside it. | Control of pause, resume and human waits belongs in code, not in an LLM loop. |
| Pocock software-factory #1316 | Stateless runs that **never wait for a human**. There is no conversational coordinator in the factory. | Remote, triggered runs. The human's next change is a new trigger. |
| Addy Osmani anti-pattern C | **No orchestrator.** The user runs /spec, /plan and /build. | The orchestrator loses human checkpoints, drifts through paraphrased hand-offs, and doubles the tokens (`REFS/addyosmani-agent-skills/references/orchestration-patterns.md:316-326`). |
| pstack v1 (removed 2026-09-07) and Anthropic | Coordinator ceremony loses on small work | 12-unit job: 1 landed against 12 for a plain agent. Anthropic measured 15× the tokens. |
| Separate planner agent | No source found that separates human-facing planning from the coordinator. firstmate sends **planning** tasks to crewmates, but it keeps the **intake questions** itself. | — |

## 4. What this says about our decision

1. One coordinator that grills, plans and spawns is the majority pattern: firstmate, Factory, openclaw, Pocock and Cognition 2026. No source puts the human-facing planner in a separate agent.
2. A fresh writer and a fresh reviewer per ticket matches the strongest shared reasons: context rot, the single-threaded write, and the clean-context reviewer (Cognition 2026, pstack, Factory).
3. Keeping memory in GitLab matches "truth outside the chat" (Pocock wiki, firstmate, pstack store, Pocock factory). The coordinator stays restartable.
4. The real risks come from the counter-sources. The coordinator loop can drift (Sokolin), so loop mechanics belong in a script. Paraphrased briefs drift (Addy), so pass the human's words verbatim. Small work pays the full ceremony (pstack v1), so let a one-ticket task skip the coordinator.
5. The relay of worker questions is our deviation from pstack. It still fits: workers can never reach the human directly, everywhere. Keep briefs complete, so the relay stays rare.
