# Archive

This folder holds the design history of the agent factory: the research files, review rounds, drafts, session
handoffs, the open-items list and the first design, architecture and development pages. It is frozen: nothing here is
kept current, and `make lint` does not check its links. Each file sits at `docs/archive/<its original path>`, so
`research/24-coordinator.md` is now `docs/archive/research/24-coordinator.md` with the same line numbers. The git tag
`design-archive-2026-11` marks the last commit before the move; an old `path:line` citation resolves there as written.
The four research files the rulebook's rules cite by path stay live in `research/`: `47-industry-migrations-obs.md`,
`48-industry-recheck-code.md`, `48-plugin-reference-pointers.md` and `49-modern-java.md`.
